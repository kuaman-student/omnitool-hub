Interactive User Guide

How to Use the 1,050+ Tools

The catalog groups common utilities into shared workspaces. Each workspace shows the operation it actually supports; unfinished operations are clearly marked and do not generate substitute results.

01

Instant Command Search

Press Ctrl + K anywhere to search by keyword, category, or exact tool number (`#1` to `#1050`).

02

Task-Specific Inputs

Workspaces show inputs for implemented operations. If an operation is not ready, the page says so instead of treating another file type as valid input.

03

Direct Share (No Download)

Click "Share Output Directly" in the bottom bar to send generated PDFs, PNGs, ZIPs, or text straight to WhatsApp, Telegram, Email, or AirDrop without saving to disk first.

04

Download or Deep-Link

Click "Download Output" to save locally, or click "Tool Link" to share a direct URL (`?tool=ID`) that opens that exact tool immediately.

Local Processing Details

How This Platform Works & Where Your Data Goes

Implemented file operations process files locally in your browser. OmniTool Hub does not upload files to a processing server. The page and its libraries load from external CDNs, and using browser sharing or a linked external service can send content to the destination you choose.

STAGE 1 • LOCAL INGESTION

Browser Memory (`ArrayBuffer`)

Supported operations read files in browser memory. Files are not uploaded for processing; the page does load its interface and libraries from external CDNs.

STAGE 2 • IN-BROWSER COMPUTE

PDFLib, JSZip, Canvas & WebCrypto

Your device's own CPU and GPU assemble PDFs, compress ZIP archives, render image filters, and compute SHA-256/512 hashes locally.

STAGE 3 • INSTANT DISPOSITION

Direct Share or Ephemeral Blob

Outputs are packaged into an in-memory `File` object for `navigator.share()` or a local `Blob` download link, and wiped from RAM when the tab closes.
